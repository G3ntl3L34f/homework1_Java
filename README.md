# ДЗ1 — вариант 14 (D22)

Алгоритм: Флойд — Уоршелл. Язык: Java.

## Структура
- `src/Vertex.java` — вершина графа.
- `src/Edge.java` — ребро с весом.
- `src/Graph.java` — хранение вершин и рёбер.
- `src/FloydWarshall.java` — алгоритм и восстановление пути.
- `src/Main.java` — запуск и вывод результата.
- `src/Tests.java` — проверки.

## Запуск
Нужен JDK 8 или новее. Из папки проекта выполните:

```bash
javac -encoding UTF-8 src/*.java
java -cp src Main
```

Запуск проверок:

```bash
java -cp src Tests
```

## Результат для варианта 14
Граф неориентированный, вершины A, B, C, D, E, F.
Рёбра веса 1: A-B, B-C, B-D, B-E, C-E, D-E, E-F.

Кратчайший путь A -> F: A -> B -> E -> F.
Длина пути: 3.

`INF` означает, что между соответствующими вершинами нет пути.
